# Mesa de Partes Digital - Municipalidad de Chorrillos

# Descripción del Proyecto
Este proyecto corresponde al desarrollo de un prototipo digital para la **Mesa de Partes de la Municipalidad de Chorrillos (CIIN1205P)**. El objetivo principal es optimizar la gestión de trámites documentarios, reduciendo el volumen de archivo físico, la vulnerabilidad a errores de registro manual y agilizando la localización y trazabilidad de expedientes administrativos.

# Funcionalidades Principales
1. Registro de Expedientes: Captura y validación estricta de DNI, datos del ciudadano y trámite.
2. Generación de Código Único: Asignación automática con estructura correlativa (`CHO-2026-XXXXX`).
3. Búsqueda Eficiente: Implementación de búsqueda lineal y búsqueda binaria por código.
4. Ordenamiento de Registros: Algoritmo de ordenamiento nativo por código de expediente.
5. Persistencia de Datos: Almacenamiento permanente en archivos de texto delimitados.
